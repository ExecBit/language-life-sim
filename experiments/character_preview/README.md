# Character animation preview

Open `language_life_prototype.tscn` with F6, then F7 to browse the Motifect packs and the locally generated `A-01 / Комната` and `A-02 / Завтрак` packs. The generated clips live in `assets/animations/generated/prologue/` and are retargeted by the shared character adapter. See that directory's README for prompts and limitations. This historical interaction scene is retained only as a character preview. The game entry point is `game/prologue/prologue.tscn` (F5). Shared adapters and resources live in `game/characters/` and `assets/animations/motifect/`.

## Игровой пролог

F8 открывает `res://game/prologue/prologue.tscn` — общежитие и игровые дни 1–2. F7 остаётся просмотром анимационных паков в preview.
