# F1 — независимый языковой справочник для A0 → письменный A1

**Статус:** нормативный проект *функций* словаря; набор слов, русские значения, формы, качество поиска и интерфейс **ещё не утверждены и не испытаны**. Никаких сюжетных событий, квестов, персонажей и игрового словаря из `ACT_*` в источниках требований нет.

**Входы:** [языковая программа](LANGUAGE_PROGRAM.md), [M/G](LANGUAGE_DESIGN.md), [лексические темы](LANGUAGE_LEXICON.md), [29-групповой реестр](LANGUAGE_LEXICAL_CATALOG.json) и [116 опор-кандидатов](LANGUAGE_LEXICAL_ANCHORS.json), [языковые горизонты](LANGUAGE_MAP.md). Режим `R` требует понять входящий немецкий текст, `P` — самостоятельно передать смысл.

## 1. Основное правило

**F1 содержит всё утверждённое словарное содержание акта с самого начала.** P0–P6 не открывают слов, грамматические заметки или возможности набора. Горизонт означает только то, какие значения ожидается осмысленно использовать в соответствующем фрагменте программы.

Не отождествлять следующие множества:

- **477** уникальных поверхностных выражений из 29 **кандидатных** тематических групп (483 вхождения) — не полный нормативный список лемм, словоформ и значений. Например, `das Buch` и `Bücher` могут быть представлены в одной статье; `Sie/sie` требуют разных значений. В таблице присутствуют цельные выражения, части и формы.
- **116** минимальных выражений-кандидатов, размещённых для иллюстративной последовательности 73 языковых единиц, — не лимит словаря и не «116 новых слов», не количество выученного.
- **Полный F1** — отдельное утверждаемое множество лемм, фраз, значений и форм, выведенное из нужных M/G/LO и доступности A0, а не из конкретных игровых реплик.

## 2. Поиск и представление

1. **Немецкий → значение.** Поиск по основной форме и частотным словоформам: `nimm` → `nehmen`; `gib` → `geben`; `Bücher` → `das Buch`; `hat gefunden` → `finden` (Perfekt).
2. **Русский → немецкий.** По смыслу, включая разговорные бытовые формулировки: «где» → `wo`; «нельзя / запрещено» → `nicht dürfen`; «не обязательно» → `nicht müssen`. Несколько семантически допустимых результатов показываются как альтернативы с пояснениями, а не автоматически склеиваются в готовый ответ.
3. **Словарные статьи не должны терять формы.** Для существительного: род, единственное/множественное, краткий смысл; для глагола: инфинитив, основные необходимые спряжения, повелительное наклонение, Perfekt там, где он введён; для устойчивой фразы: собственное цельное значение.
4. **Грамматический смысл.** Краткие сравнения `nicht/kein`, `du/Sie/sie`, `im/ins`, `möchten/mögen`, `hätte gern`, `doch`, отделяемых глаголов, Perfekt с `haben/sein`. Тонкая грамматика не подменяет обязательный понятный смысл.
5. **Полисемия и неопределённость.** Разные значения `sein` («быть» и притяжательное «его» в соответствующей форме), `morgen` («завтра»), `der Morgen` («утро»), `Sie/sie` и частотных предлогов представлены раздельно; неоднозначность не превращается в ошибочный единственный перевод.
6. **Свобода обращения.** В обычной игре F1 разрешён на любом шаге, не мешает вводить частичные понятные фразы, не ухудшает результат игрового действия и не считается доказательством изучения слова. Возможность попросить повторить остаётся отдельной.
7. **Не решать задачу за игрока.** F1 показывает отдельные значения/формы/грамматические закономерности и нейтральные примеры. Не подставляет готовое немецкое предложение под текущую коммуникативную цель, не выделяет нужный ответ как правильный.
8. **Итоговая независимая оценка** (отдельный пересдаваемый этап) проверяет без F1/готовых подсказок. Доступность словаря в обычной игре и независимая оценка — два разных режима; экзамен не определяет набор словарных единиц.

## 3. Минимальная схема записи

| Поле | Для чего |
|---|---|
| `entry_id`, `sense_id` | стабильная статья и конкретное значение, исключающие смешение омонимов |
| `lemma`, `surface_forms[]` | форма поиска, написание, артикль, формы числа/времени |
| `ru_meanings[]` | понятные новичку русские эквиваленты и альтернативные запросы |
| `part_of_speech`, `gender`, `plural` | минимальные языковые свойства, когда применимы |
| `grammar_tags[]` | G-ID, отрицание, направленность, модальность, время |
| `phrase_variants[]` | цельные устойчивые единицы и падежные/личные варианты |
| `R_or_P_role`, `horizon` | *планируемая необходимость* значения в программе, **не доступность в F1** |
| `meaning_note` | контраст смыслов без раскрытия готового решения |
| `status` | `approved` / `candidate` / `needs_disambiguation`; кандидат не выдаётся за проверенную статью |

Если словоформа или контекст допускает несколько значений, искать по всем совместимым `sense_id` и показывать короткое предупреждение о различии.

## 4. Независимые проектные проверки

| ID | Запрос или немецкий Input | Требуемый результат |
|---|---|---|
| F1-01 | Русское «где» | `wo` доступно **с начала** |
| F1-02 | `nimm`, `gib` | `nehmen`, `geben` и смысл повеления |
| F1-03 | `Bücher` | `das Buch`, форма множественного числа |
| F1-04 | «не обязан» против «нельзя» | `nicht müssen` и `nicht dürfen` не подменяют друг друга |
| F1-05 | `im Zimmer` и `ins Zimmer` | место против пункта назначения |
| F1-06 | `sie` и `Sie` | третье лицо и вежливое обращение различимы по контексту |
| F1-07 | `hat gefunden` | лемма `finden`, завершённое действие |
| F1-08 | `ist gegangen` | лемма `gehen`, Perfekt с `sein` |
| F1-09 | «брат» / «сестра» / «друг» | независимые роли и значения, без утверждения чьей-либо биографии |
| F1-10 | «люблю читать» | `gern` + `lesen` и простой смысл интереса |
| F1-11 | `doch` при отрицательном вопросе | нельзя переводить просто как всегда одинаковое «да» |
| F1-12 | неизвестная форма / опечатка | честно показать неопределённость или несколько вариантов, **не** выдавать ложную уверенность |

Эти 12 случаев — **тестовый дизайн, а не пройденные тесты**. Для проверки на настоящем A0 следует выяснить не только, что запись нашлась, но и может ли новичок выбрать нужный смысл без скрытого знания немецкого.

## 5. Независимый аудит форм в немецких примерах

Дополнительная сверка [73 языковых единиц и 80 немецких A/B-пар](LANGUAGE_PRACTICE_UNITS.json) с [независимым каталогом](LANGUAGE_LEXICAL_CATALOG.json) дала **146** разных немецких словоформ: **113** буквально встречаются в поверхностных выражениях каталога, **31** требуют словоформного сопоставления с уже присутствующей леммой, **2** — условные имена, которые не должны автоматически становиться словарём. Ранее отсутствовавшие `froh`, `traurig`, `acht`, `elf`, `zwölf`, `da`, а также `dort`, `wohin` и `sehen` теперь входят в независимый каталог; их включение **не** означает автоматическую обязательную продукцию или новый словарный лимит.

**Важно:** это статический разбор только текстовых примеров, не тест словарного UI. Совпадение токена с каталогом само по себе не гарантирует правильного значения, переводов или полноты склонений. Все **33** случая и предполагаемые леммы сохранены в `program_form_alias_candidates` каталога. Ни один сценарный документ не использовался.

**Дополнительный контроль независимой рецепции:** шесть проектных LO-R-кейсов содержат **47** разных немецких словоформ. **40** буквально встречаются в каталоге; остальные семь — четыре условных имени и три глагольные формы (`darfst`, `musst`, `bring`), требующие словоформного сопоставления. Полная разметка находится в `independent_assessment_receptive_forms` [лексического каталога](LANGUAGE_LEXICAL_CATALOG.json). Это не проверка понимания пользователями.

## 6. Независимый проект поисковых соответствий

В [основном лексическом реестре](LANGUAGE_LEXICAL_CATALOG.json), в поле `f1_candidate_search`, теперь оформлены:

- **50 кандидатов сопоставления словоформ и устойчивых конструкций с леммой** (включая `nimm → nehmen`, `hat gefunden → finden`, `fängt an → anfangen`, `ist gegangen → gehen`).
- **49 русских поисковых запросов-кандидатов**, в том числе «где/куда», «не обязан/нельзя», «цена», «брат/подруга», «утро/завтра» и числительные. Для всех результирующих немецких форм проверено наличие записи в независимом каталоге.
- **15 групп контекстной неоднозначности**: `Sie/sie`, `wo/wohin`, `morgen/der Morgen`, `im/ins`, отрицательные модальные формулы, `gern/lieber`, `sein` и другие.
- Для неизвестного запроса предусмотрено честное отсутствие результата или несколько кандидатов. **Не** надо выводить один «правильный» перевод при неоднозначности.

**Это кандидатная схема поиска, не готовый движок F1, не полный обратный индекс 477 слов и не проверка работы словаря.** Весь реестр из 477 единиц снабжён черновыми русскими значениями, но полноценные формы, полисемия, поисковые синонимы и интерфейс остаются на проверку. Скрипт [analyze_language_load_balance.py](../tools/analyze_language_load_balance.py) включает статическую валидацию реестра и ссылок из `f1_candidate_search` в режиме `--check`; реальное выполнение команды в этом окружении **не проводилось**.

## 7. Проверка доступности ранних горизонтов

Для каждой из абстрактных единиц P0–P2 в [основной программе](LANGUAGE_PRACTICE_UNITS.json) до предъявления задачи необходимо проверить:

- имеются ли в F1 все **критические** слова и понятные формы, без которых отличие A/B нельзя распознать;
- достаточно ли известных предыдущих языковых опор для самостоятельного P, и не требует ли слово на экране отдельного сложного правила;
- не даёт ли русский UI или подсветка сам правильный ответ в обход немецкого;
- можно ли безопасно уточнить/переспросить и продолжить без принудительной ложной реплики «не понимаю»;
- не нагружен ли один языковой контакт одновременно новым словарём, модальностью, отрицанием, адресатом и временем.

**Проведена только методическая ревизия рисков A0–P2:** девять конкретных единиц отмечены `a0_readiness_review` в [основной последовательности](LANGUAGE_PRACTICE_UNITS.json). В том числе разнесены на два смысловых контакта время и отделяемые глаголы P2c-04; M18/M54 в P2c-03 разрешено только рецептивно по целым модальным выражениям до продуктивного G22 в P3b; для M08 исключён вводящий в заблуждение пример с `Sie` в начале предложения без контекста. Эти изменения уменьшают методический риск, но **не заменяют проверки на A0**.

**Результат LP09 на текущем этапе:** критерии сформулированы; **ни один реальный F1 UI, Godot-парсер, пользователь A0 или отсроченный тест не запускался**. Пока нет утверждённого полного словаря с переводами и формами, невозможно закрыть реальные пункты F1-01…12 и объявить ранние единицы проверенно доступными.
