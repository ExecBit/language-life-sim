# LP11 — независимая проверка 13 результатов письменного A1: банк задач v0.1

**Статус:** проектный банк заданий; **не принято как финальный экзамен, не реализовано, не проверено на учащихся**. Источники требований: [LEARNING_OUTCOMES.md](LEARNING_OUTCOMES.md), [LANGUAGE_DESIGN.md](LANGUAGE_DESIGN.md), [LANGUAGE_PROGRESSION.md](LANGUAGE_PROGRESSION.md), [LANGUAGE_LEXICON.md](LANGUAGE_LEXICON.md). Проверка проводится **без подсказки F1, Лены и раскрытого русского ответа**; сюжет первого акта не даёт заданиям готовое решение.

### Общий контракт

- Для **R** игрок должен извлечь смысл из нового короткого немецкого текста/записи; правильный ответ нельзя угадать по подсвеченному предмету или русскому UI. Для **W** — самостоятельно передать нужное сообщение немецкими словами без единственного ожидаемого предложения.
- **Новый контекст, знакомые языковые опоры:** данные (имена, часы, предметы) варьируются в пределах материала акта, смысловые конструкции знакомы. Нельзя вводить новые обязательные темы только ради экзамена.
- **Неиспользованный ранее факт:** проверка не цитирует дословно уже показанную обязательную сцену. Два варианта отличаются решающим фактом, а не перестановкой кнопок.
- **Обратная связь:** задача решена, не решена или требует уточнения. Грамматическая/орфографическая ошибка, не меняющая смысл, не блокирует. Отрицание, получатель, время, действие, объект, направленность, запрет/разрешение — критические различия.
- **Отложенное повторение:** отдельная добровольная вторая попытка после иной деятельности. Не считать одну успешную попытку долгосрочным усвоением.

| **W01** | В другом помещении у NPC есть нужный предмет, но неизвестно, где он лежит | Задать конкретный вопрос или попросить предмет/помощь; ответ NPC зависит от намерения | Заменить нужный предмет/человека при похожем внешнем виде | Сообщить факт вместо запроса или назвать другой предмет |

| **W04** | Собеседник предлагает два безопасных вида отдыха/напитка, у героя есть предпочтение и состояние | Выразить предпочтение/потребность и кратко отреагировать | Поменять собственную потребность (задана в мире) или выбор собеседника | Сообщить противоположное желание; нельзя требовать идеальную форму `möchte` |
| **W05** | Другой персонаж не видел сделанную героем проверку; результат — новый факт, отличный от вчерашней записи | Передать агент, событие и важное изменение короткими фразами | Изменить объект проверки или статус | Сообщить прошлое как текущее или чужое действие как своё |

Все приведённые тексты — **примеры формы**, не финальные неизменные задания. На первом акте нужно обеспечить предварительную **осмысленную практику** всех существенных смысловых различий, иначе соответствующий LO нельзя честно проверять.

## 2. Семантическая рубрика

У каждого варианта есть скрытый для игрока контракт: `known_to_player`, `unknown_to_recipient`, `required_facts`, `critical_contrasts`, `acceptable_intents`, `clarification_route`, `valid_outcomes`. Эти поля **не обязаны** быть названиями JSON-ключей движка, пока не выбран формат.

- **2 балла** — смысл установлен/передан полностью, включая необходимые различия; грамматика может быть несовершенной.
- **1 балл** — основное намерение выражено, но один некритический пункт отсутствует или есть естественная уточняемая неоднозначность; уточнение не считается провалом обучения, но до разрешения не ставить 2.
- **0 баллов** — противоположный смысл в критическом параметре, чужой агент/адресат, неверные данные или отсутствующий самостоятельный запрос.

**Для R** можно использовать 0/1/2 как число правильно извлечённых независимых смысловых частей, но не оценки правописания. **Для W** 1/2 не зависит от склонения, если намерение однозначно. Для `W07` минимум два содержательных пункта обязательны, иначе максимум 1, даже при идеальной грамматике.

Не суммировать автоматически все задания в один проходной балл до согласования весов и правил: одно неверное `nicht dürfen` может быть значительнее одного пропущенного вежливого слова. Предлагается отчёт **по 13 LO** с отдельными критическими ошибками и числом обращений за помощью, а не «A1 получен/не получен».

## 3. Контроль честности экзамена

1. **Разграничение источников:** немецкое задание содержит нужный факт; русский UI не сообщает его до решения, подсветка и маршрут не показывают ответ.
2. **Информационная асимметрия:** для P-ответа адресат не слышал нужного сообщения и не видит локальное наблюдение; не делать сообщение декоративным.
3. **Семантические варианты:** для каждого LO минимум один контрфакт, который меняет только решающий смысл, и один допустимый вариант свободной формулировки.
4. **Право на уточнение:** реальная неоднозначность вызывает просьбу уточнить, а не отказ за неверный порядок слов; отсутствие знания не обязывает говорить «не понимаю».
5. **Проверка без F1** оценивает самостоятельное применение **здесь и сейчас**, но не долговременную память и не весь официальный CEFR.
6. **Экзамен не обучает новому:** если неизвестный язык блокирует ответ, это дефект программы/экзамена, а не автоматическая вина игрока.
7. **Вторая форма задач** с новыми данными должна обнаруживать простое копирование/угадывание, но не превращаться в зубрёжку.

## 4. Условия готовности LP11

**Сделано проектно:** 13 независимых заданий с изменяемым решающим смыслом, границами допустимых ответов и критериями критических ошибок. **Не сделано:** финальные UI-сценарии, балльный порог, вес критических ошибок, независимая оценка парсером, тест на A0 и отсроченная проверка.

**Нужны отдельные решения пользователя:** является ли такой формат итоговой проверки желательным, нужна ли вообще единая проходная оценка, какие результаты обязательны для финальной сюжетной развязки. Пока не объявлять экзамен утверждённым.
