## 4. Как интерпретировать отсутствие

- **Разные R-лексемы в данном дне** = встреченные хотя бы раз в обязательном немецком тексте, включая фоновые/служебные слова.
- **P-примеры** не добавляются к обязательным R-контактам. Слово может не использоваться в авторском примере, хотя игрок выразит нужный смысл синонимом.
- **5 пустых дневных слотов** — только фильтр для просмотра, не забывание и не рекомендованный интервал.
- Перерывы в **проектных днях** не соответствуют времени в реальном мире.
- Кандидаты ядра и ситуационной лексики требуют авторского утверждения; слова без назначенной роли остаются видны и не считаются ненужными.
- Для существенной проверки нужны отдельные **needed_R/needed_P** контракты и варианты диалогов, чтобы не принимать автоматические упоминания слов за осмысленную практику.
