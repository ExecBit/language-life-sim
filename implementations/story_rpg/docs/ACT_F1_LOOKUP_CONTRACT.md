# LP04 / LP09 — контракт F1 и границы словаря первого акта

**Статус:** проектный интерфейсный и лексический контракт, не реализация и не утверждённый F1. Весь словарь акта доступен с начала игры; P0–P6 определяет языковые потребности и практику, не блокировку слов.

**Данные:** [реестр корпуса и каталога](ACT_F1_COVERAGE_MANIFEST.json), [черновые русские значения 221 единицы](ACT_F1_GLOSS_CANDIDATES.json), [29 тематических групп](LANGUAGE_LEXICON.md), [проверки A0](ACT_A0_INPUT_READINESS_REPORT.md). Источники разного уровня: **199** нормализованных R-единиц из обязательных реплик; **8** дополнительных, встречающихся только в обязательных авторских P-примерах; **207** уникальных единиц обязательного пути; ещё **14** единиц только в факультативном корпусе; **221** единица текущих авторских R/P-сцен вместе; **458** уникальных тематических слов/выражений в 29-групповом каталоге (не обязаны быть отдельными леммами). **221 ≠ полный F1**, а 458 ≠ «458 выученных слов».

## 1. Минимальная структура записи

| Поле | Смысл | Пример |
|---|---|---|
| ID значения | Различает омонимы и грамматические функции; **не** только строка | `sie.3sg` / `Sie.formal`; `sein.verb` / `sein.possessive` |
| Немецкая лемма и формы | Корректная словарная форма + встречающиеся формы текста | `nehmen`: `nimm`, `nehme`; `dürfen`: `darf`, `darfst` |
| Русские краткие значения | Одна/несколько **проверенных** формулировок для обратного поиска | `где` → `wo`; `нельзя` → `nicht dürfen` |
| Род/число | Для существительных, включая употребление в контексте | `der Arzt`, `die Ärztin`, `das Zimmer` |
| Категория | Роль в функции (не оценка памяти игрока) | базовая коммуникативная / предметная / контекстная |
| Пример **значения** | Один короткий контекст для различения значений, **не готовый ответ на квест** | `im Zimmer` (где) vs `ins Zimmer` (куда) |
| Происхождение | Отмечает обязательный R, пример P, общий тематический каталог | scene/event ID или 29-группа |
| Статус редакции | Кандидат, проверено лингвистически, интегрировано | нельзя «проверено в игре» без UI |

Нужно сохранять словарные записи из утверждённой общей языковой матрицы, даже если соответствующая фраза не встретилась в конкретной сцене.

## 2. Доступность для абсолютного A0

1. **Поиск от русского намерения:** запрос `где` находит `wo`, даже если слово **ещё не встречалось в R**. Запрос `нужна помощь` возвращает леммы `brauchen`, `Hilfe` и подходящие короткие значения, но не выдаёт целиком обязательную реплику.
2. **Поиск от услышанного/прочитанного немецкого:** `nimm` находит `nehmen`, `brauchst` — `brauchen`, `darf` — `dürfen`; наивный точный поиск по лемме непригоден.
3. **Разрешение неоднозначности:** `sie` может быть «она/они», а `Sie` — формальное «Вы»; `sein` — «быть» либо «его»; `morgen` — завтра, `der Morgen` — утро; `zu` — закрыто/к/слишком. Контекст и написание показывать явно, без принудительного выбора одной трактовки.
4. **Смысловая разница без морфологического экзамена:** `im/ins`, `nicht müssen / nicht dürfen`, `mein/dein`, `mir/dir` должны быть доступны как значения и контрасты, не как набор правил для механического теста.
5. **Грамматическая опора:** существительные с родом/множественным числом, инфинитивом и частотными формами глагола; короткие предложения допустимы как примеры, но не с подстановкой конкретных данных текущего квеста.
6. **Свобода:** F1 не блокирует ходы и не считает обращение к нему «штрафом» или доказательством изучения слова. Продуктивный ввод остаётся свободным.
7. **Лексический контекст:** слово может встретиться единожды как фоновое; наличие в F1 не превращает его в обязательный экзаменационный элемент. Не нужен индекс «памяти» для 207/458 слов.

## 3. Конкретные технические долги данных

| Проблема | Причина | До применения в UI |
|---|---|---|
| `wo` отсутствует среди 199 обязательных R | Нужен **раннему P**, встречается в 5 авторских обязательных P-примерах | F1 собирается из **матрицы + каталога + R + P**, а не только из R |
| `darf` и `dürfen` как разные нормализованные элементы | В форме настоящего времени из P используется `darf`; в R есть `darfst` | Связать с одной глагольной леммой, не теряя видимые формы |
| `Zeit` и `zeit` | Непоследовательный регистр в нормализации | Привести к одному словарному значению без слома тематических тегов |
| `problems` | Родительная форма `Problems` сохранена как самостоятельная лемма | Каноническое `Problem`, форма `Problems` |
| `sie/Sie`, `sein`, `zu`, `morgen` | Одной пары «строка → перевод» недостаточно | Добавить ID значений и примеры; учитывать регистр и соседние слова |
| 155 не классифицированных обязательных R-лексем | Нынешние 27 core / 18 situational — предварительные роли | Не считать неразмеченное «одноразовым мусором». Классифицировать **по функции**, а не частоте |
| 458 тематических единиц | Не совпадают 1:1 с 207 лексемами, включают устойчивые фразы и новые формы | Включать после проверки ценности для M/G/LO; покрытие **всего актового F1** пока не доказано |

**Не менять нормализацию прямо сейчас без синхронного пересчёта** всех отчётов и HTML: текущий числовой срез 199/207 обусловлен существующей машинной моделью словаря.

## 4. Контрфактические тесты F1

| Тест | Ввод | Ожидаемый результат |
|---|---|---|
| F1-01 | Русское `где` на первом событии | `wo` найден по смыслу, не после «разблокировки» |
| F1-02 | Немецкое `nimm` в сообщении Лены | `nehmen` и «возьми» найдены |
| F1-03 | Немецкое `darfst` и `darf` | Один глагол `dürfen`; сопоставление разрешения |
| F1-04 | `nicht müssen` vs `nicht dürfen` | Нет смешения «не нужно» и «запрещено» |
| F1-05 | `im Zimmer` vs `ins Zimmer` | Различимы «в комнате» и «в комнату» |
| F1-06 | `sie` vs `Sie` в двух обращениях | Видны разные значения, регистр и адресат |
| F1-07 | `Ich brauche den Schlüssel` как цель квеста | F1 показывает отдельные слова/общую грамматику, **не готовый сценарный ответ** |
| F1-08 | Неизвестное немецкое склонение/форма | Находится понятная лемма либо честно показана неоднозначность; не выдаётся ложный перевод |
| F1-09 | Запрос `не понимаю` | Найдены `verstehen` + `nicht` и готовая **общая** метафраза `Ich verstehe nicht`; игрок не обязан её произносить |
| F1-10 | Поиск вне текущего горизонта | Актовый словарь доступен с начала без открытия уровнем |

## 5. Что реально выполнено

**Готово:** машиночитаемый список 199 R-лемм + 8 дополнительных P-only обязательного пути + 14 только факультативных, все 29 тематических групп с 458 исходными единицами и **черновая** русская подсказка для 221 нормализованной единицы. Нет отсутствующих машинных форм в текущем обязательном R-корпусе.

**Не готово:** каноническая редакция 458 словосочетаний с переводами, родами/формами и омонимами, обратный индекс, интеграция Godot/F1, приемочные проверки F1-01…10 с абсолютным A0. Не выдавать этот документ за доказательство существования полного рабочего словаря.
