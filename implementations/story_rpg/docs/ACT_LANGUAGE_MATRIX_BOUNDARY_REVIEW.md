# LP02 — содержательное ревью границ M01–M55 и G01–G34

**Статус:** независимый проектный аудит по [LANGUAGE_DESIGN.md](LANGUAGE_DESIGN.md), [LANGUAGE_MAP.md](LANGUAGE_MAP.md), [LANGUAGE_PROGRESSION.md](LANGUAGE_PROGRESSION.md) и [13 LO](LEARNING_OUTCOMES.md). **Не** изменение языковой матрицы: 55 функций и 34 грамматических блока сохраняются, независимо от сюжетных примеров.

## 1. Результат ревью перекрытий и соседних функций

| Группа | Не путать | Предлагаемая граница приёмки |
|---|---|---|
| **M06 / M39 / M40** | Распознать вопрос/просьбу ≠ извлечь факт из реплики ≠ выполнить инструкцию | M06 — смысл речевого действия; M39 — понимать нужную информацию NPC, M40 — выполнить указание, **не по подсветке**. Один эпизод может давать свидетельство нескольким ID, но разные цели должны быть явными |
| **M07 / M47 / M05** | Спросить неизвестное ≠ короткий письменный запрос по жанру ≠ запросить разъяснение непонятого | M07 — недостающий факт; M47 — самостоятельный запрос сведений по короткому тексту/адресату; M05 — только **реально нужна** просьба разъяснить. Не делать `Ich verstehe nicht` обязательным |
| **M09 / M10 / M15** | Назвать вещь ≠ различить признаки двух вещей ≠ сообщить **изменение** или неисправность | В игре нужен смысл объекта и состояния; нельзя засчитывать все три только за слово `Sensor` |
| **M11 / M54 / M18** | «Нет объекта» ≠ общий `nicht` ≠ разрешение/запрет/обязанность | `kein`, `nicht dürfen`, `nicht müssen` — самостоятельные значимые контрасты; не требовать идеальной морфологии, но не принимать противоположный смысл |
| **M13 / M14 / M53** | Принадлежность ≠ получатель действия ≠ местоименная ссылка | `mein/dein`, `mir/dir`, `er/sie/es` проверять контрфактами с двумя владельцами/адресатами/референтами |
| **M16 / M28 / M51** | **M16:** сопоставить/противопоставить два факта; **M28:** сравнить величину/качество; **M51:** рассказать о **собственном прошлом результате** | Все три **не дублируют** друг друга; один инженерный отчёт может содержать все три, но не доказывает их перенос. M16 не обязывает `aber`; M28 не требует безошибочного окончания `größer`; M51 не требует идеального Perfekt |
| **M20 / M21 / M22** | Место сейчас ≠ куда идти ≠ прочитать `im/ins` | M20/M21 — P-смысл положения/назначения, M22 — R-контраст. Нельзя объявлять M22 освоенным по двум дверям, если одна явно закрыта |
| **M23 / M24 / M25 / M27** | Часы/дата ≠ договорённость ≠ частота ≠ длительность | M25 — отдельная самостоятельная частота (`oft/manchmal`) при изменении планов, не декоративное слово; M27 — R-ядро границы `bis/seit`, не обязательная продуктивная длительность |
| **M29 / M30 / M31 / M32 / M38** | Самочувствие ≠ желание ≠ предпочтение ≠ потребность в еде ≠ препятствие | Можно применять в одной медицинской или бытовой сцене, если **различные решения** действительно зависят от них; нельзя требовать все виды описания при одном ответе |
| **M33 / M34 / M35 / M36 / M37** | Работа ≠ интересы ≠ эмоциональное отношение ≠ личные связи ≠ приглашение | Интересы и личные связи — самостоятельные языковые функции, и обе обязательны по текущему указанию пользователя. Отсутствие в нынешнем сюжете не мешает проектировать языковые контракты; `müde/froh` не заменяет `M34/M36` |
| **M41 / M42 / M43 / M44 / M45** | Знак ≠ таблица ≠ личный/рабочий текст ≠ форма | Это **жанры чтения**, а не пять наборов лексем. Минимум знакомого короткого текста и самостоятельное извлечение. Форма с `Sensor/Zeit/Status` допускается для M45, личные поля не обязательны |
| **M46 / M48 / LO-W07** | Сообщить два собственных пункта ≠ перенести чужое сведение другому | M46 — составное сообщение/несколько собственных реплик; M48 — сохранение информации при смене адресата; LO-W07 может брать свидетельства из обоих, но не требует длинного письма |
| **M49 / M50 / M51 / M52** | Отметить время ≠ прочесть прошлое ≠ рассказать собственный опыт ≠ запланировать будущее | В P5 разные источники и собеседники; `M50` не засчитывать по одной знакомой форме, `M52` не требует Futur I |
| **M08 / M55 / G33** | Формальное **Sie** ≠ `sie` третьего лица; рецептивная вежливая формула ≠ обязательный Konjunktiv II в письме | Оставить **R-only**; применять в осмысленном служебном обращении/просьбе без учебного упражнения и без принуждения к грамматически идеальному ответу |

## 2. Грамматический минимум: что проверять отдельно от слов

| Блоки | Что является содержательной целью | Что не делать обязательным |
|---|---|---|
| **G01–G08** | Распознать простое высказывание, вопрос, приказ, лицо/действие | Точная пунктуация/глагольное окончание как условие прохода при ясном смысле |
| **G09–G13** | Род/число, объект действия, `kein` и признак; правильный выбор вещи | Безупречный артикль в свободной речи; угадывание по одному подсвеченному объекту |
| **G14–G18** | Владелец, адресат, положение, направление | Правильное падежное окончание важнее того, кому/куда идёт предмет |
| **G19–G27** | Время, числительные, модальность, предпочтение, частота и последовательность | Изолированный тест грамматики вместо осмысленного изменения плана |
| **G21** | Узнать, что начало смены/вызов выражено отделяемым глаголом и найти **время/действие** | Учить абстрактный «отделяемый глагол» без значимого факта; закрывать по `beginnt` без `fängt … an` |
| **G28–G30** | Прошлое с `war`, `habe geprüft`, `ist gekommen/ausgefallen`; различить чей факт и когда | Требовать всех форм сильных глаголов, считать факультативное `angekommen` обязательной практикой |
| **G31–G34** | Рецептивные свойства, частотные безличные фразы, готовая вежливость, связка простых мыслей | Склонение прилагательного/полный Konjunktiv II; обязательное длинное предложение с `aber` |

**Частичная исходная неоднозначность:** в таблице G21/G30 отмечено `R/P-смысл`, что **не** равняется обязательной полной продуктивной морфологии; цель — понимать/передать значение действия даже простыми словами. Для честного аудита нужно отдельно отмечать наличие нужной R-формы и **свободной передачи смысла** без требования произнести ту же форму.

## 3. Проверка раннего A0 и поздней границы A1

- **P0:** приветствие и базовые короткие действия могут начинаться с имитации — это доступный старт, не доказательство памяти. Нельзя заставлять отвечать без понимания `Wo`, `Nimm` и состояния игрока.
- **P1–P2:** один значимый объект, свойство, владелец, адресат, место; разрешить короткие и неполные фразы. Не требовать одновременно социального регистра, Perfekt и обязательного объяснения причин.
- **P3–P4:** условия и расписания, предпочтения, текст/формы, личное общение. Для каждого нового смысла важен более поздний контекст, а не «день урока».
- **P5:** прошедшее время как личная история и рабочий отчёт; настоящее+будущее для планов. Структуры должны быть знакомы к финалу.
- **P6:** независимая комбинация заранее встреченных смыслов; не добавлять новые обязательные леммы, жанры, модальность или грамматику.

## 4. К чему приводит ревью

**Не найдено оснований автоматически удалить** M16/M28/M51, M27/M55 и пересекающиеся жанровые функции: это разные **смыслы** и разные источники данных, даже если изучаются одновременно. Но их нельзя считать «пятью отдельными уроками».

**Уточнение после аудита:** M34/M36 обязательно включены в языковую программу и не требуют утверждать биографию NPC. Вежливые обращения M08/M55 формируются как независимые рецептивные требования, не как правила общения конкретного экипажа. Для G21/G30 отделять распознавание значимой формы от требования безупречной продуктивной морфологии. Эти решения сведены в [LANGUAGE_CORE_DECISION_GATE.md](LANGUAGE_CORE_DECISION_GATE.md).

До дальнейшего методического согласования матрицу M/G и 13 LO **не менять**; статусы LP10 относятся к текущему **сценовому корпусу**, а не готовности языковой программы. Ревью — фильтр ложных объединений/лишних грамматических требований, не автоматическое принятие всех 89 элементов программы.
