# Изолированные реализации

Каждый игровой вариант находится в собственной директории `implementations/<variant>/` и содержит собственные сцены, код, парсер, диалоги, сценарии, состояния, UI и тесты. Варианты не импортируют код и данные друг друга.

Общие зависимости находятся в корне: `addons/` — Cogito и прочие плагины, `assets/animations/` — анимации, `assets/characters/` — модели. Не перемещать Quaternius и Motifect из их исходных мест. Отдельные игровые реализации могут использовать эти общие ресурсы, но не должны изменять их ради собственных требований без согласования.

`project.godot` один на весь репозиторий; F5 сейчас запускает `res://implementations/dormitory/game/prologue/prologue.tscn`. Для других вариантов используйте F6 на их сцене. У каждого варианта должны быть собственные имена файлов сохранений в `user://`.

Текущий вариант — `dormitory/` (общежитие, магазин и связанные эксперименты). Сюжетные документы разных сеттингов не означают, что их игровые системы можно напрямую связывать.
